### [AntiHotkey](https://www.nexusmods.com/warhammer40kdarktide/mods/1316)

Prevents DMF hotkeys from triggering while typing in chat.

Includes a whitelist system so you can pick and choose which mods (like DMF) bypass the protection.

Just go into the mod folder then find the `anti_keybinds.lua` file and edit the `whitelisted_mods` section to add or remove mods.
