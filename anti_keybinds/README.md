### [Anti Keybinds](https://www.nexusmods.com/warhammer40kdarktide/mods/XYZ)

Prevents DMF hotkeys from triggering while typing in chat, using the mouse cursor, or navigating menus.

Includes an easy-to-use whitelist system so you can define which mods (like DMF itself) bypass the protection.
